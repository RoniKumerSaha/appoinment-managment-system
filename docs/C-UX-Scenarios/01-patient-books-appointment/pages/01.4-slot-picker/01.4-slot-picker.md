# Page 01.4 — Slot Picker

**Scenario:** 01 — Patient Books an Appointment
**Persona:** Maya (Patient)
**Position in flow:** Step 4 — the moment of truth

---

## Purpose

Show real availability for the selected doctor + branch + type, within the 30-day window. No fake slots, no approximations. Patient conflict rules are reflected here, not at submit.

## Exit action

Tap a slot → `01.5-contact-info/` (everything pre-selected).

## Components

| Component | Notes |
|---|---|
| Context bar | Doctor + branch + type, fixed at top. |
| Conflict warning | If patient already has a future appointment with this doctor (BR-031) or overlapping appointments (BR-033), warning shown above the slot list. The slots are still shown — she can see what's available — but the warning makes the eventual block visible. |
| Date scroller | Horizontal scrollable dates, today disabled, dates past 30 days disabled. Earliest bookable is tomorrow (BR-021). |
| Slot list | Vertical list per selected day. Real-time. Each slot shows time + book button. Slots that overlap her existing appointments are hidden, not greyed. |
| Booking window notice | Footer text: "Today and dates after Sep 14 are not available." |

## Behavioral notes

- **Real-time availability.** Slots disappear the moment they're taken by another patient. This is the BG-3 guarantee made visible.
- **Patient conflict rules are surfaced here, not at submit.** If she has an overlapping appointment, the conflicting slots are *hidden*. If she has a same-doctor future appointment, a warning is shown at the top of the slot list. The submit step has nothing to refuse; the rules are enforced before the patient reaches it.
- **Same-day is disabled** (FR-019 / BR-021). Today is unselectable in the date scroller.
- **30-day window is the hard ceiling** (FR-018 / BR-020). Dates past day 30 are unselectable.
- **No same-doctor double-book.** If she already has a future appointment with this doctor, all slots are still shown but the submit step will refuse — *with the warning visible here* so she doesn't waste time picking.

## Empty / error states

| State | UI |
|---|---|
| No availability in the next 30 days | "No available times in the next 30 days. Try another doctor or branch." (Link to doctor list.) |
| Day has no slots | Day still selectable but slot list shows "No times available on this day." |
| Branch has no operating hours this week | "This branch has no upcoming operating hours. Try another branch." |
| Patient is over the same-doctor future-appointment limit and chooses to proceed | Submit blocked: "You already have a future appointment with Dr. Ahmed on Aug 22 at 10:00. You can only have one upcoming appointment per doctor." |

## Accessibility

- Date scroller uses arrow buttons + swipe; keyboard navigable.
- Slot list is a listbox; current selection is announced.
- Live region for "slot taken by another patient" updates.

## Mobile vs desktop

Mobile: date scroller + slot list stack vertically. Desktop: two-column on wide screens (date left, slots right).

## Performance note

PRD NFR-008: ≤ 2 seconds for typical availability queries. The slot picker must be lazy — load slots for the selected day only, not all 30 days at once. Cache per doctor/branch/type/day for the session; refresh on date change.
