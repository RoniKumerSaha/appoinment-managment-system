Doctor manages the appointment types they offer. Active types appear in patient booking. Inactive stay bookable for existing appointments but hidden from new bookings. CRUD with confirmation on changes that affect future bookings.

Table + Inline Edit. Standard data table — name, duration, bookings (30d), status, updated. Row actions: Edit / Deactivate / Duplicate. Familiar admin pattern. Best for power users with many types.
