§7.1–7.2 · Buttons & Pills

Actions & status

Four button variants. Status pills never use brand teal — that color is for actions.

Rules
  • One primary CTA per visible region — never two.
  • Destructive actions are always .btn-danger. Never primary-red, never ghost-danger.
  • Disabled = opacity:0.5. Never remove the label.
  • Pill text is always uppercase, 10–11px, weight 600–700.
